# Markdown 語法

### Markdown 是什麼？

> Markdown 是一種輕量級標記式語言，它允許人們使用易讀易寫的純文字格式編寫文件，然後轉換成有效的XHTML（或者HTML）文件。
> 
> 由於 Markdown 的輕量化、易讀易寫特性，並且對於圖片，圖表、數學式都有支援，目前許多網站都廣泛使用 Markdown 來撰寫說明文件或是用於論壇上發表訊息。
>
>  <br> — Markdown - 維基百科，自由的百科全書 - Wikipedia

## 標題語法

| Markdown語法      | 預覽效果 |
| :----------- | :-----------: |
| `# Heading level 1` | <h1>Heading level 1</h1> |
| `## Heading level 2` | <h2 style="border-top: none; margin: 0 ; padding: 0;">Heading level 2</h2> |
| `### Heading level 3` | <h3 style="margin: 0 ;">Heading level 3</h3> |
| `#### Heading level 4` | <h4>Heading level 4</h4> |
| `##### Heading level 5` | <h5 style="font-size: 0.83em ;">Heading level 5</h5> |
| `###### Heading level 6` | <h6 style="font-size: 0.67em ;">Heading level 6</h6> |

## 段落語法

「段落」只需要用空白行分隔不同段落即可，Markdown 會自動把它們視為獨立段落

| Markdown語法      | 預覽效果 |
| :----------- | :----------- |
| `I really like using Markdown.`<br><br>`I think I'll use it to format all of my documents from now on.` | <p>I really like using Markdown</p><p>I think I'll use it to format all of my documents from now on.</p> |

## 換行語法

在 Markdown 語法中，換行有2種方式可以達成

- 結尾加兩個空白再換行
- Markdown 可以直接嵌入 HTML，因此也可以用 HTML 的 <br> 標籤來換行

| Markdown語法      | 預覽效果 |
| :----------- | :----------- |
| `This is the first line. __ or <br>`<br>`And this is the second line.` | <p>This is the first line.<br>And this is the second line.</p> |

## 強調語法

### 粗體

| Markdown語法      | 預覽效果 |
| :----------- | :----------- |
| `I just love **bold text**.` | I just love <strong>bold text</strong>. |

### 斜體

| Markdown語法      | 預覽效果 |
| :----------- | :----------- |
| `Italicized text is the *cat's meow*.` | Italicized text is the <em>cat's meow</em>. |

### 同時使用 粗體 & 斜體

| Markdown語法      | 預覽效果 |
| :----------- | :----------- |
| `This text is ***really important***.` | This text is <strong><em>really important</em></strong>. |

### 底線

| Markdown語法      | 預覽效果 |
| :----------- | :----------- |
| `This text is __underlined__` | This text is <u>underlined</u>. |

### 刪除線

| Markdown語法      | 預覽效果 |
| :----------- | :----------- |
| `This text is ~~strikethrough~~.` | This text is ~~strikethrough~~. |
